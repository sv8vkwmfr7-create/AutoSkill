核心能力

  • 全链路自动生成：召回 → LLM 终审 → 生成（四层校验 + ≤3 轮自修正）→ 入库热加载 → 调用
  • 治理闭环：熔断隔离 → 影子验证修复 → 自动回滚 → 自动回退到最近稳定版本
  • 五层沙箱纵深：AST 白名单 / 受限内建命名空间 / PEP 578 审计钩子 / 内存看门狗 / Docker 可切换
  • egress 域名白名单：HTTP 类技能四点校验（操作员拥有出站策略）
  • 跨语言召回：混合部署（chat 与 embedding 独立配置），英文改述召回中文技能
